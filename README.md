### 👋 Who I am

I'm a data scientist who loves the whole journey: grabbing a messy public dataset, building the pipeline and
warehouse underneath it, finding the story in it, and shipping something people can actually click.

- 🚀 **Founding Data Scientist** at LabVue, building the startup's data pipelines, dashboards and experiments from scratch
- 🎓 **M.S. Data Science**, Indiana University Bloomington
- 🏆 **1st Prize, Smart India Hackathon 2022**
- 🥈 **Runner-up, UNESCO India Africa Hackathon 2022**
- 🔍 **My rule:** every number gets checked against the data before it goes anywhere. If a finding doesn't hold up, it doesn't ship.

> Somewhere between Python, SQL, data pipelines and a mildly concerning number of LLM calls is usually where you'll find me. 🤓

### 💪 What I'm good at

| | |
|---|---|
| 🏗️ **Data warehouses that refuse bad data** | dbt medallion layers, data contracts, slowly changing history, DuckDB locally and Snowflake in production |
